# 血月幸存者 · BloodMoon Survivors

一款致敬《Vampire Survivors》的横版俯视角 roguelike 生存游戏。纯前端实现，**所有像素素材与音效均由程序实时生成**，零外部资源依赖。

## 怎么玩

- **直接双击 `index.html`** 即可开始（或用任意静态服务器打开本目录）。
- 目标：在血月之下存活 **20 分钟**，撑到黎明降临即胜利。
- 击杀敌人掉落经验宝石，自动吸附拾取；升级时三选一强化。
- 精英怪（发光大只）掉宝箱；每 5 分钟出现一个头目。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 移动 |
| 武器 | 全自动攻击，无需操作 |
| Esc | 暂停 |
| M | 静音 |

## 内容一览

- **3 名角色**：猎人（血鞭）/ 法师（魔杖）/ 骑士（巨斧），各有属性差异。
- **11 种武器**（各 8 级）：血鞭、飞刀、魔杖、巨斧、圣蒜光环、圣书环绕、天罚闪电、圣十字、炼狱火瓶、毒图腾、虚空黑洞。
- **武器进化**：武器满级 + 指定被动满级后开宝箱触发进化（如 血鞭+力量之证=血月之鞭），进化拥有强化弹幕与专属播报。
- **10 种被动道具**：力量、冷却、护甲、移速、范围、磁石、回血、经验、幸运、分身。
- **8 种小怪 + 3 个头目 + 1 追踪精英**：蝙蝠、僵尸、骷髅、幽灵、小恶魔、史莱姆、大恶魔、暗影猎手（短冲刺追踪）；死神（冲锋）、血岩傀儡（震地）、吸血鬼领主（召唤）——头目血量过半会**狂暴**。
- **15 个定时事件**：蝙蝠环、僵尸墙、天使治疗圈、火墙走廊、宝箱雨、恶魔潮、暗影猎手、终局大军……
- **金币 + 永久强化**：对局中拾取金币，结算存入银行，主菜单商店可购买 4 项永久加成（生命/伤害/移速/拾取）。
- **触屏支持**：移动端虚拟摇杆（pointer events，模拟量移动）。
- 最佳纪录本地保存；WebAudio 合成音效与暗黑风循环 BGM（随时间加层）；主菜单背后是 AI 实机演示对局。

## 技术说明

- 零依赖 vanilla JS，固定 60Hz 步长模拟，空间哈希碰撞，支持 300+ 同屏敌人。
- 文件结构：`index.html` / `js/sprites.js`（字符像素画烘焙）/ `js/audio.js`（合成音效+BGM）/ `js/content.js`（武器/敌人/事件数值）/ `js/game.js`（引擎）。
- 调试与自动化测试：URL 加 `?debug=1`（性能面板）、`?autotest=1&speed=4&t=600`（自动开局/加速/跳时间）、`?ai=1`（AI 走位）、`?build=秒`（典型 build 模拟）、`?nogod=1`（关闭无敌）、`?nodemo`（关闭菜单演示）；页面控制台有 `window.GAME` API（spawn/levelUp/god/skip/give/setW/chest/buildout 等）。
